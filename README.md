# python-labs

Premiers scripts Python : affichage et saisie utilisateur.

## Contenu

- `bonjour.py` : affiche « Bonjour Python »
- `bonjour_input.py` : demande un prénom, puis l'affiche avec sa longueur

## Utilisation

Windows :

```
python bonjour.py
python bonjour_input.py
```

macOS / Linux :

```
python3 bonjour.py
python3 bonjour_input.py
```
